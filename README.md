# SLCM 0–5 Population Data Analysis

This repository contains Part 1 of our group project analyzing South Louisville Community Ministry's 0–5 population data.

## Team Members

- Graydon Laughlin
- Tudor Iordan

## Project Overview

The goal of this project was to explore, clean, and better understand SLCM's intake and household-member data.

The analysis focuses on:

- Housing and eviction risk
- Employment and income
- Household composition
- Repeat contact
- Data quality issues

## Files

- `SLCM_Part_1.ipynb` — Jupyter notebook containing the analysis, cleaning steps, and plots
- `Group Project Part 1.docx` — Written report and documentation
- `cleaned_intakes_masked.csv` — Intake dataset
- `household_members_long_v2.csv` — Household-member dataset

## Tools Used

- Python
- pandas
- NumPy
- Matplotlib
- Seaborn

## Main Findings

- About 28% of profile-level tickets showed active eviction risk.
- Employment status alone did not fully explain financial hardship.
- The typical household had about 3 people and commonly included 2 children.
- About 34% of unique PIDs appeared on more than one ticket.
- Several data-quality issues were identified and documented.

## Note

The data is de-identified and should only be used for this course project.
